# 专利文件导入工具 — 图形界面（UI）操作说明

本文档面向使用 **桌面图形界面版本** 的用户，详细说明如何从启动程序到完成专利文件上传的全过程。

> 命令行（CLI）版本的使用请参考 [CLI工具使用文档](./CLI工具使用文档.md)。

---

## 一、软件简介

专利文件导入工具是一款桌面应用程序，用于将本地的 Excel 专利文件批量导入到服务器。整个操作被设计为一个**自上而下的 4 步向导流程**：

1. **服务器配置** — 设置服务器地址与登录信息
2. **列名映射配置（可选）** — 把 Excel 中的列名转换为目标字段名
3. **文件处理** — 扫描源文件夹并准备 / 转换文件
4. **文件上传** — 将文件批量上传到服务器

界面右侧固定显示**操作指南**（当前进度）和**操作日志**，方便随时了解状态。

---

## 二、界面总览

启动程序后，主窗口分为三个区域：

- **顶部导航栏**：显示软件标题、连接状态指示灯、当前步骤名称以及步骤进度圆点。
- **左侧主操作区**：依次展开 4 个步骤的折叠面板，是主要的操作区域。点击每个步骤标题栏可展开（▼）或收起（▶）。
- **右侧辅助区**：上方为「操作指南」（标示当前进行到哪一步），下方为「操作日志」。

![主界面总览](placeholder-主界面总览.png)

> **进度指示说明**：
> - 顶部和右侧的步骤圆点中，**绿色** = 已完成，**蓝色** = 当前步骤，**灰色** = 尚未开始。
> - 顶部连接状态指示灯：**绿色** = 连接成功，**红色** = 连接失败，**黄色** = 警告，**蓝色** = 提示信息。

## 三、操作步骤详解

### 步骤 1：服务器配置

程序启动后默认展开此步骤。

1. **服务器地址**：填写服务器的完整地址，例如 `https://api.example.com`（需包含 `http://` 或 `https://`）。
2. **用户名**：填写登录账号（用户名或邮箱）。
3. **密码**：填写登录密码。点击输入框右侧的 👁️ 图标可切换密码的明文 / 密文显示。

![服务器配置](placeholder-服务器配置.png)

填写完成后有两个按钮：

- **测试连接**：在保存前先验证服务器是否可访问。点击后按钮变为「测试中…」，结果会在下方以彩色提示框显示：
  - ✅ 绿色「服务器连接正常」表示可正常访问；
  - ❌ 红色表示无法连接，请检查地址或网络。
- **保存配置**：保存当前填写的服务器信息。保存成功后会自动**收起本步骤并展开步骤 2**。

> **提示**：
> - 「测试连接」和「保存配置」按钮在三项信息未填写完整前为灰色不可点击状态。
> - 配置会被自动保存，下次打开程序时会自动恢复，无需重复填写。

![连接测试成功](placeholder-连接测试成功.png)

---

### 步骤 2：列名映射配置（可选）

此步骤用于把 Excel 文件中的**原始列名**转换为服务器需要的**目标列名**。

> **何时需要？**
> - 如果你的 Excel 列名与服务器要求的字段名**不一致**，需要在此处配置映射。
> - 如果列名**已经正确**，无需转换，可直接跳过本步骤，程序将上传原始文件。

#### 添加映射

1. 点击底部的 **➕ 添加映射** 按钮，新增一行映射。
2. 每行包含两个输入框，中间用 `→` 连接：
   - 左侧填写 **原列名**（Excel 中的列名）；
   - 右侧填写 **新列名**（服务器需要的字段名）。
3. 如需删除某行映射，点击该行右侧的 ❌ 图标。

![列名映射配置](placeholder-列名映射配置.png)

#### 导入 / 导出映射配置

为方便复用，支持配置文件的导入导出（JSON 格式）：

- **导出配置**：将当前所有映射保存为 `.json` 文件，便于备份或分享。
- **导入配置**：从之前导出的 `.json` 文件读取映射，自动填充列表。

#### 完成本步骤

底部提供多个操作按钮：

- **保存映射**：保存当前所有有效映射（空白行会被自动过滤），完成后自动进入步骤 3。
- **清空所有**：删除所有已配置的映射（会弹出确认提示）。
- **跳过配置** 或面板下方的 **「跳过列映射，直接处理文件」**：不进行任何列转换，直接使用原始 Excel 文件进入下一步。

> **重要区别**：
> - 若**配置并保存了映射** → 步骤 3 会执行「转换」，需要额外指定**目标文件夹**用于保存转换后的文件。
> - 若**跳过映射** → 步骤 3 只做文件准备，**无需目标文件夹**，直接上传原始文件。

---

### 步骤 3：文件处理

本步骤用于扫描源文件并准备待上传的文件列表。

#### 1. 选择源文件夹

在「文件夹配置」中点击 **源文件夹** 输入框或右侧的 **浏览** 按钮，在弹出的对话框中选择包含 Excel 文件的文件夹。

![选择源文件夹](placeholder-选择源文件夹.png)

#### 2. 选择目标文件夹（仅配置了列映射时显示）

- 若在步骤 2 配置了列映射，此处会出现 **目标文件夹** 输入框，请选择转换后文件的保存位置。
- 若跳过了列映射，此处显示蓝色提示「当前未配置列映射，将直接上传原始 Excel 文件，无需指定目标文件夹」，无需操作。

#### 3. 扫描文件

点击 **扫描文件** 按钮。扫描完成后，会显示「扫描结果」面板：

- **Excel 文件**：发现的 Excel 文件数量；
- **总大小**：所有文件的总大小；
- **文件列表**：列出扫描到的文件名（可滚动查看）。

![扫描结果](placeholder-扫描结果.png)

#### 4. 开始转换 / 准备上传

扫描出文件后，第二个按钮可点击：

- 配置了列映射时按钮显示为 **开始转换**，会按映射规则转换文件并保存到目标文件夹；
- 跳过映射时按钮显示为 **准备上传**，直接准备原始文件。

处理过程中会显示进度条，完成后出现绿色的「转换完成 / 已准备 N 个文件」提示，并自动进入步骤 4。

![转换完成](placeholder-转换完成.png)

---

### 步骤 4：文件上传

本步骤将处理好的文件批量上传到服务器。

#### 1. 选择导入模式

在「导入模式」下拉框中选择本次上传的范围：

| 选项 | 含义 |
| --- | --- |
| **所有专利** | 上传文件中的全部专利记录 |
| **仅发明专利** | 只导入发明专利 |
| **仅有效发明专利** | 只导入处于有效状态的发明专利 |

![导入模式选择](placeholder-导入模式选择.png)

#### 2. 开始上传

点击 **开始上传**。程序会先用步骤 1 中保存的账号自动登录服务器，登录成功后逐个上传文件。

上传过程中可使用的控制按钮：

- **暂停 / 继续**：临时暂停上传，再次点击继续。
- **清除已完成**：清空已成功上传的记录（上传进行中不可用）。

#### 3. 查看上传进度

界面会实时展示：

- **总进度条**：显示 `已完成 / 总数` 文件数及整体百分比。
- **上传列表**：每个文件一行，带有状态图标——
  - ⏳ 等待中（pending）
  - 📤 上传中（uploading）
  - ✅ 已完成（completed）
  - ❌ 失败（failed）
- **上传统计**：分别统计「等待中」「已完成」「失败」的文件数量。

![上传进度](placeholder-上传进度.png)

#### 4. 处理失败的文件

若某个文件上传失败，该行会变红并显示错误信息，右侧出现 **重试** 按钮。单个文件失败**不会中断**整体流程，其余文件会继续上传，失败的文件可稍后单独点击「重试」。

#### 5. 完成

当所有文件上传成功后，界面顶部会出现 🎉「上传完成！」的提示，表示全部操作结束。

![上传完成](placeholder-上传完成.png)

## 四、操作日志（右侧栏）

右侧的「操作日志」区域记录每一步的详细信息，便于排查问题。

- **日志级别过滤**：通过 INFO / WARN / ERROR / SUCCESS 按钮可切换显示对应级别的日志（高亮为显示中）。
- **日志统计**：分别统计四种级别日志的数量。
- **清空日志**：清除当前所有日志记录。
- **导出日志**：将日志保存为文件，便于反馈问题时提供给技术支持。

## 五、常见问题（FAQ）

**Q1：「测试连接」一直失败怎么办？**
请确认服务器地址完整（含 `http://` 或 `https://`）、网络通畅，并检查服务器是否正常运行。

**Q2：扫描后「开始转换」按钮是灰的？**
需要先成功扫描出至少一个 Excel 文件；若配置了列映射，还需选择目标文件夹。

**Q3：部分文件上传失败？**
单个失败不影响其他文件。可在上传列表中找到红色失败项，点击「重试」单独重新上传；如仍失败，请导出日志检查具体错误信息。

**Q4：每次都要重新填服务器配置吗？**
不需要。服务器配置和列映射会自动保存，下次启动自动恢复。

**Q5：Linux（Ubuntu 24）下输入框卡死？**
这是 Tauri/WebView 与 Linux 输入法的兼容性问题，请使用 `patentupload.sh` 启动脚本运行，详见 [Ubuntu输入框卡死问题解决方案](./Ubuntu输入框卡死问题解决方案.md)。

## 六、完整操作流程速览

```
启动程序
  └─ 步骤1 填写服务器地址/用户名/密码 → 测试连接 → 保存配置
       └─ 步骤2 （可选）配置列名映射 → 保存映射 / 跳过配置
            └─ 步骤3 选择源文件夹（必要时选目标文件夹）→ 扫描文件 → 开始转换/准备上传
                 └─ 步骤4 选择导入模式 → 开始上传 → 查看进度 → 🎉 完成
```
